# Contributing to Visionary Verse

Thank you for your interest in contributing to Visionary Verse!

## Development Setup

1. Clone the repository
2. Configure your database settings in `config/database.php`
3. Import the SQL schema from `SQL_QUERIES.sql`
4. Start your local PHP server

## Code Standards

- Follow PSR-12 coding standards for PHP
- Use meaningful variable and function names
- Comment complex logic
- Test your changes before committing

## Branch Strategy

- `project-manager` - Production-ready code and Project manager features
- `startup-manager` - Startup manager features
- `quality-manager` - Quality manager features
- `risk-manager` - Risk manager features
- `Scheduling-manager` - Scheduling manager features

## Submitting Changes

1. Create a feature branch from the appropriate base branch
2. Make your changes
3. Test thoroughly
4. Commit with clear, descriptive messages
5. Push to your branch
6. Create a pull request

## Questions?

Contact the project maintainers for any questions or concerns.
